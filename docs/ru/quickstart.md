# Быстрый старт

За несколько минут: поставить сервер, указать ему заметки, убедиться, что он их находит, и дать ассистенту записать первую строку.

## 1. Установка

```bash
uv tool install worklog-mcp
```

Команда `worklog-mcp` появляется в `PATH`. Больше ничего не нужно: у сервера нет ни состояния, ни собственного файла конфигурации.

## 2. Проверьте, что лог находится

Прежде чем прописывать сервер в клиент, спросите саму команду:

```bash
worklog-mcp check --dir ~/notes
```

```text
ok: file="2026-09-06.md" items=3
```

Это тот файл, в который писал бы `append`, и число пунктов, которые уже есть в его первом чек-листе. Если ответ не `ok`, [страница про командную строку](guide/cli.md) сопоставляет каждый код возврата с тем, чего не хватает.

Если в каталоге лежат не только логи, сузьте выбор регулярным выражением по имени файла:

```bash
worklog-mcp check --dir ~/notes --pattern '^\d{4}-\d{2}-\d{2}\.md$'
```

## 3. Пропишите сервер в клиент

=== "OpenCode"

    ```json
    {
      "mcp": {
        "worklog": {
          "type": "local",
          "command": ["worklog-mcp", "serve", "--dir", "/path/to/your/notes"]
        }
      }
    }
    ```

=== "Claude Code"

    ```bash
    claude mcp add worklog -- worklog-mcp serve --dir /path/to/your/notes
    ```

=== "Общий вид"

    ```json
    {
      "mcpServers": {
        "worklog": {
          "command": "worklog-mcp",
          "args": ["serve", "--dir", "/path/to/your/notes"]
        }
      }
    }
    ```

Перезапустите клиент. Появятся два инструмента, `append` и `check`, с префиксом из имени, которое вы дали серверу.

## 4. Запишите первую строку

Попросите ассистента записать то, что он только что сделал. Он вызовет `append` с одной фразой и отчитается файлом и строкой:

```text
one item was appended to the checklist in "2026-09-06.md"
- [x] исправил импорт CSV в сервисе отчётов, причина — необработанная пустая строка
```

Попросите ещё раз той же фразой — ничего не произойдёт, вызов вернётся со статусом `duplicate`. Чтобы увидеть строку, не записывая её, у инструмента есть `dry_run`.

# worklog-mcp

**MCP-сервер, который записывает сделанную работу в ваш дневной лог.** Укажите ему каталог с лог-файлами — он допишет один выполненный пункт в чек-лист самого свежего из них.

---

## Зачем это нужно

Если вы ведёте заметку на день с чек-листом сделанного, ассистент, который эту работу выполнил, может записать строку сам — ровно в тот момент, когда работа закончена. Настраивать это ради одной строки стоит из-за того, где живёт конфигурация: каталог задаётся аргументом запуска и читается локальным процессом, поэтому он никогда не проходит через диалог. Модель просит об одном — допиши эту фразу — и узнаёт два факта: в какой файл записано и какая строка туда попала.

Остальное в устройстве сервера следует из того, что его пускают в чужие заметки:

<div class="grid cards" markdown>

-   :material-folder-lock: **Путь не попадает в диалог**

    Задаётся один раз при старте. В результатах всегда имя файла и никогда — каталог.

-   :material-file-hidden: **Лог-файлы не создаются**

    Об отсутствии файла или каталога сообщается, и вызов останавливается. Заводится только недостающий чек-лист.

-   :material-repeat-off: **Повторный вызов безопасен**

    Пункт, который уже есть в чек-листе, не пишется второй раз — перезапуск сценария не задваивает строку.

-   :material-format-align-left: **Ваше форматирование сохраняется**

    Отступ, маркер списка и переводы строк берутся из файла, а запись атомарна.

</div>

## Как это выглядит

Лог-файл до:

```markdown
# 2026-09-06

- [x] просмотрел релизный чек-лист
- [ ] разобраться с падениями импорта
```

Ассистент вызывает `append` с текстом *исправил импорт CSV в сервисе отчётов, причина — необработанная пустая строка*, и файл становится таким:

```markdown
# 2026-09-06

- [x] просмотрел релизный чек-лист
- [ ] разобраться с падениями импорта
- [x] исправил импорт CSV в сервисе отчётов, причина — необработанная пустая строка
```

Больше в файле ничего не сдвинулось.

!!! info "Требования"

    Python 3.13+ и любой MCP-клиент. Ни редактор, ни формат хранилища, ни приложение для заметок не предполагаются: лог-файл — это любой текстовый файл с markdown-чек-листом внутри.

## Установка

```bash
uv tool install worklog-mcp
```

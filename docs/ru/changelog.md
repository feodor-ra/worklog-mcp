# История изменений

Здесь описаны все заметные изменения проекта.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [0.1.0] — 2026-09-06

### Добавлено

- Первый выпуск. MCP-сервер с двумя инструментами: `append` дописывает один
  выполненный пункт в первый чек-лист самого свежего файла каталога, `check`
  сообщает, что это за файл и сколько пунктов в нём уже есть.
- Лог-файлу без чек-листа список заводится в конце, что возвращается статусом
  `created`. Сам лог-файл по-прежнему не создаётся.
- Настройка только при запуске — `--dir` / `WORKLOG_DIR` и `--pattern` /
  `WORKLOG_FILE_PATTERN`, — благодаря чему каталог никогда не проходит через
  диалог, а в результатах не бывает путей файловой системы.
- Подкоманда `worklog-mcp check` для диагностики настройки из терминала, с
  кодами возврата, различающими отсутствие каталога, отсутствие лог-файла и
  отсутствие чек-листа.
- Импортируемый Python API, на котором построены оба инструмента: `Worklog`,
  `AppendResult`, `CheckResult`, `WorklogError` и `build_server`.
